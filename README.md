# Simple Navigation

A simple Android application created to learn and demonstrate **basic screen navigation** using **Kotlin** and **Android Studio**.

## Download

[Download APK](https://github.com/s-modak09/Simple-Navigation/releases/download/v1.0.0/app-debug.apk)

## Features

- Simple two-screen navigation
- Navigate from the first screen to the second screen
- Clean and simple user interface
- Basic Android Navigation Component implementation
- Beginner-friendly project for learning navigation

## How It Works

The application contains two screens:

**First Screen → Second Screen**

1. Launch the application.
2. The **First Screen** is displayed.
3. Tap the navigation button.
4. The application navigates to the **Second Screen**.

## Technologies Used

- Kotlin
- Android Studio
- Android SDK
- AndroidX
- Navigation Component
- Gradle
